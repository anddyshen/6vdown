# C2Down · 电影站下载解析器（Windows 桌面版）

> 一个带系统托盘的 Windows 桌面工具：
>
> - 解析剪贴板中的**磁力链接 / PT 站点直链 / HTTP 资源链接**，并推送到 **qBittorrent / Transmission / Aria2** 下载器；
> - 按设定（含备用镜像地址）解析目标电影站首页的中部更新列表与详情页磁力链接，以【电影名称 · 对应日期 · 资源简介】形式列出，勾选后一键添加至下载器；
> - 具备**增量更新提示、重要资源星标（红色链接 / "经典"字样）、右下角渐变提醒、可拖拽接收链接的小窗、操作历史记录**等能力。
>
> 最终打包为 **Windows 单文件 `.exe`**。

## 功能需求

### 一、基础功能

#### B1 剪贴板解析与发送

- 自动监听剪贴板，识别并解析以下内容：
  - **磁力链接**：`magnet:?xt=urn:btih:<40 位 hex>...`
  - **PT 站 http(s) 直链**：如含 `passkey` / `download.php` 的可直投链接 → 直接发送至下载器；
  - **普通 http(s) 资源直链** → 发送至下载器；
  - **需登录的 http 链接** → 使用用户在设置中填写的 Cookie 抓取详情页提取真实下载地址；未配置 Cookie 时给出明确提示。
- 一键将解析结果发送至**当前激活的下载主机**。

#### B2 下载主机设置

- 设置项：下载器类型（qBittorrent / Transmission / Aria2）、主机地址、端口、用户名、密码；
- 密码本地加密存储（Windows DPAPI）。

#### B3 多下载主机管理

- 支持新增 / 编辑 / 删除多个下载主机配置；
- 可**激活**其中一台作为默认发送目标，激活状态全局生效且可随时切换。

#### B4 系统托盘

- 最小化 / 关闭主窗口时**常驻右下角任务栏托盘**；
- 托盘菜单：显示主窗口 / 显示拖拽小窗 / 禁用（暂停解析与提醒）/ 退出；
- **禁用时托盘图标变灰**（预生成灰阶图标进行切换）。

#### B5 程序图标

- 独立设计"电影 + 磁力"主题图标，生成多分辨率 `.ico` 嵌入 exe。

#### B6 右下角提醒弹窗

- 成功添加下载任务后在右下角弹出提醒（任务名、目标主机）；
- 弹窗**定时自动关闭**，支持**渐变淡入 / 淡出**（与 A4 通知复用同一组件）。

#### B7 操作痕迹与历史记录

- 后台 SQLite 记录每次操作：任务名称、磁力 / 链接、发送的服务器、发送时间、来源（剪贴板 / 网站解析 / 手动）、执行结果；
- 历史记录页支持**查询、删除、再次触发添加**（将原任务重新发送至下载器）。

#### B8 可拖拽小窗

- 独立小悬浮窗：网页链接 / 磁力文本可**直接拖入**添加任务；
- 小窗可**显示 / 隐藏**，可自由移动、置顶，位置可记忆。

### 二、进阶功能（指定网站解析与自动下载）

#### A1 首页解析与备用镜像

- 解析首页（默认 `https://www.hao6v.cc/`）的**中部更新列表**，并提取每个条目的：
  - 电影名称、对应日期、详情页 URL；
  - 是否为**红色链接**、标题文字是否含 **"经典"**；
- 后台可**设置多个备用地址**，主站失败时自动按序切换；
  - 已探明同源镜像：`6v520.net` / `6v520.cc`（旧版）、`xb6v.com` / `hao6v.org`（新版）；
  - 地址发布页：`6v123.com`，可作"自动发现新域名"的可选数据源。
- 解析主流程：
  1. 抓取首页（按 gb18030 → utf-8 顺序尝试解码）→ 定位更新列表；
  2. 逐条抓取详情页 → 提取全部磁力链接；
  3. 汇总为【电影名称 · 对应日期 · 资源简介】列表；
  4. 解析结果**落库**，作为后续增量比对的依据。

#### A2 增量对比

- 每次解析与**上一次成功解析结果**对比，仅列出上次之后新增的记录；
- **首次解析展示全量**。

#### A3 重要资源星标

- 命中以下任一条件，在结果列表中该项前加 ⭐：
  - 首页记录行为**红色链接**；
  - 记录文字中包含 **"经典"**。

#### A4 激活任务状态机

- 启动后解析任务默认**待激活**；
- 点击"激活解析"后弹出确认，询问是否在后台执行：
  - 选择执行 → 后台**静默**完成解析；
  - 期间打开任务视图 → 以**命令行实时滚动**方式展示解析进度（QProcess 捕获子进程 stdout）；
- 执行成功后 → 右下角弹窗（**渐变出现 → 停留 → 渐变消失**），提醒用户打开结果页；
- 结果页每条记录带 **checkbox** 与 **【添加至下载】** 按钮，支持**逐条添加**与**勾选后统一添加**（页面底部"全部添加"）。

## 目标站点情报（侦察结论）

| 项目 | 结论 |
| --- | --- |
| 站点 | `https://www.hao6v.cc/`（= `https://www.6v520.net/`，同一站点同模板同内容） |
| 编码 | **GBK / gb18030**（按 UTF-8 直接解析会乱码） |
| 页面形态 | 纯静态 HTML，无 JS 渲染、无验证码 / WAF；单次请求约 42 KB |
| 更新列表 | 首页中部多个带 `[MM-DD]` 日期的更新区块，标题形如 `2026高分剧情《…》1080p.HD国语中字` |
| 区块 | 电影更新区、"经典高清电影"区、"最新更新的电视剧（红色为推荐）"区、分集剧区等 |
| 红链 / 经典 | 页面存在"红色为推荐"说明；"经典"出现于区块标题与条目文字 |
| robots / sitemap | 均不存在（404） |
| 域名风险 | 站群频繁更换域名（近期已有 6+ 新域名），备用地址功能为核心依赖 |

> 注意：列表的确切 DOM 选择器、详情页磁力容器写法、红链标记方式，需在 M0 阶段以真实 HTML 校准。

## 数据模型（草稿）

| 表 | 字段要点 |
| --- | --- |
| `download_hosts` | 类型、名称、地址、端口、用户名、加密密码、是否激活 |
| `task_log` | 任务名、磁力/链接、目标主机、来源、时间、结果状态 |
| `parse_records` | 电影标题、日期、详情 URL（主键）、简介、磁力列表(JSON)、是否红链/经典、首次发现时间 |
| `mirror_sites` | 备用地址、是否启用、最近可用状态 |
| `settings` | 激活主机、解析区块选择、弹窗时长、自动解析开关等 |

## 风险与限制

1. **域名失效**：备用镜像 + 发布页探测缓解，但无法保证任一域名永久可用；
2. **站点改版**：可能破坏解析规则；规则集中管理便于快速修复，解析失败自动告警；
3. **PT 登录墙**：仅支持带 passkey 的直链；需登录页面依赖用户配置 Cookie，不实现登录绕过；
4. **未来反爬**：当前无验证码 / WAF；若出现则提供“手动粘贴链接”降级路径；
5. **打包体积**：PySide6 单文件 exe 约 50–90 MB。

## 已确认实现决策

1. **界面**：单窗口多标签（工作台 / 历史 / 设置）；主题默认跟随系统亮/暗，可手动切换。
2. **解析区块**：首页解析覆盖 最新电影 / 经典高清 / 更新电视剧 / 国剧 / 日韩剧 / 美剧 / 动画，
   并在设置页提供**区块勾选开关**（关键词匹配定位，措辞差异免疫）。
3. **剧集分集**：详情页磁力按其链接文字（“第 X 集”等）**分组列出**，可逐集发送/复制，
   也可一键发送全部。
4. **镜像容灾**：设置页支持随时**添加/删除/设为当前/检测可用性**；检测可一键覆盖全部域名，
   并可从 `6v123.com` 发布页**自动发现新域名**；解析时自动降级到可用镜像。
5. **开机自启**：设置页开关（写注册表，打包后生效）。
6. **定时自动解析**：本期仅预留 `AutoParseController` 接口，后续版本启用。
7. **HTTP 链接策略**：磁力 / .torrent / PT 直链自动发送；普通网页链接默认弹窗询问
   （设置可改为一律发送或忽略）。
